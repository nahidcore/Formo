Checks

Expected results make it easy to pinpoint deployment and browser problems.

What to do when a check fails

  • Backend or topics API fails: deploy a new Apps Script Web App version and confirm the endpoint in js/schema.js is its /exec URL.
  • Topics count is zero: the connection is healthy; create a topic from admin to add the first shared topic.
  • Storage fails: allow site data/cookies for this site or leave private browsing. Drafts and local topic cache need browser storage.
